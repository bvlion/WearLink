【WearLink】プライバシーポリシー

当方が提供するアプリケーション「WearLink」（以下「本アプリ」と言います。）における情報の取り扱いについて、以下のとおりお知らせします。

1. Firebase Crashlyticsによる情報の取得

本アプリは、不具合の発見・修正およびアプリの安定性向上を目的として、Google社が提供する「Firebase Crashlytics」を利用しています。取得される情報には、アプリがクラッシュ（異常終了）した場合のクラッシュレポートに加え、モバイル端末とWear OS端末の間の通信同期に失敗した場合など、クラッシュには至らないエラーを記録した非致命的（non-fatal）なエラーレポートが含まれます。

取得情報

  • アプリがクラッシュ（異常終了）した際のスタックトレースやエラー内容
  • モバイル端末とWear OS端末の間の通信同期に失敗した場合など、クラッシュに至らないエラーが発生した際のスタックトレースやエラー内容
  • 上記発生時のアプリのバージョン情報
  • 端末情報（機種名、OS のバージョンなど）
  • Crashlytics インストール ID 等の関連識別子

利用目的

  • 不具合の発見・修正
  • アプリの安定性向上

これらの情報は、当方が独自に用意したサーバーではなく、Google社が提供する Firebase Crashlytics に送信され、Google社によって収集されます。
収集された情報は、Google社の仕様に基づき収集から 90 日で削除が開始されます（Firebase のプライバシーとセキュリティを参照）。この保存期間は当方が独自に定めたものではありません。

本アプリは、Firebase Analytics（利用状況分析）を利用していません。

2. ユーザーが本アプリ内に保存する情報

本アプリは、ユーザーが作成・実行する HTTP リクエストに関する以下の情報を、Android の標準的な仕組み（Jetpack DataStore）を用いてアプリのローカルストレージに保存します。

  • リクエストのタイトル、URL、HTTP メソッド、ヘッダー、リクエストボディ等の設定内容
  • 実行結果（レスポンスコード、レスポンスヘッダー、レスポンスボディ、実行日時等）の履歴

これらの情報は、開発者であるbvlionが運営するサーバーへ送信・保存することはありません。
一方で、本アプリはAndroidの自動バックアップ機能を無効化しておらず、専用の除外設定も行っていません。そのため、お使いの端末でバックアップ機能や機種変更時のデータ移行機能が有効になっている場合、OSの機能により上記の情報がバックアップおよび復元の対象となることがあります。バックアップされたデータの取り扱いは、Android OSまたはお使いの端末の提供元（Google等）の仕様に従います。

モバイル端末とWear OS端末をお使いの場合、上記の情報は Google Play 開発者サービスが提供する Wearable Data Layer API を通じてモバイル端末とWear OS端末の間で同期されます。当方が運営するサーバーは経由しません。

3. ユーザーが指定した送信先との HTTP 通信

本アプリの主な機能は、ユーザー自身が入力・設定した URL に対して HTTP リクエスト（GET、POST 等）を送信することです。

  • このリクエストは、ユーザーの端末からユーザーが指定した送信先へ直接送信され、当方が運営するサーバーを経由しません。
  • リクエストの送信先 URL、送信内容（ヘッダーやボディ）、レスポンス内容を、当方が取得・収集することはありません。
  • 送信先が第三者の管理するサーバーやサービスである場合、そこでの情報の取り扱いは当該サービスのプライバシーポリシーに従います。送信先の指定および送信内容についての責任はユーザーご自身にあります。

4. 情報の取得停止・削除

  • 本アプリをアンインストールすることで、Firebase Crashlytics への新たな情報の送信は停止します。
  • Google社によって既に収集された情報は、収集から 90 日で自動的に削除が開始されます（Firebase Crashlytics の仕様によるものです）。
  • 端末内に保存されたリクエストの設定内容および実行履歴は、アプリ内の削除機能またはアプリのアンインストールにより削除できます。

5. 第三者への提供

当方は法令に基づき開示・提供を求められた場合（例：裁判所の命令、法的手続きに基づく場合）に限り、取得した情報を第三者に提供することがあります。

6. プライバシーポリシーの改訂

当方はプライバシーポリシーを適宜見直し、改善を行います。
プライバシーポリシーの変更を行う際は当ページにて公表いたします。
