# 【WearLink】プライバシーポリシー

当方が提供するアプリケーション「WearLink」（以下「本アプリ」といいます。）における情報の取り扱いについて、以下のとおりお知らせします。

## 1. Firebase Crashlytics による情報の取得

本アプリは、不具合の発見・修正およびアプリの安定性向上を目的として、Google 社が提供する Firebase Crashlytics を利用しています。

### 取得される情報

Firebase Crashlytics により、以下の情報が取得される場合があります。

- アプリがクラッシュした際のスタックトレースやエラー内容
- 本アプリが記録した非致命的な例外のスタックトレースやエラー内容
- アプリのバージョン情報
- 端末情報（機種名、OS のバージョンなど）
- Crashlytics Installation UUID、Firebase Installation ID 等の関連識別子

これらの情報は、不具合の発見・修正およびアプリの安定性向上のために利用します。

取得された情報は、当方が独自に運営するサーバーではなく、Google 社が提供する Firebase Crashlytics に送信されます。

Firebase Crashlytics では、クラッシュスタックトレースおよび関連する識別子等を 90 日間保持した後、ライブシステムおよびバックアップシステムから削除するプロセスを開始します。

詳細については、以下の Firebase 公式ページをご確認ください。

- [Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy)

なお、本アプリは Firebase Analytics を利用していません。

## 2. 本アプリ内に保存する情報

本アプリは、ユーザーが作成・実行する HTTP リクエストに関する以下の情報を、本アプリのローカルストレージに保存します。

- リクエストのタイトル
- URL
- HTTP メソッド
- ヘッダー
- リクエストボディ
- その他のリクエスト設定
- レスポンスコード
- レスポンスヘッダー
- レスポンスボディ
- 実行日時等の実行履歴

これらの情報を、当方が運営するサーバーへ送信・保存する仕組みはありません。

ただし、Android のバックアップまたは端末移行機能が有効な場合、Android の機能によりこれらのデータがバックアップまたは別の端末へ復元・転送される場合があります。

端末内に保存された情報は、本アプリ内の削除機能によって削除できます。また、通常は本アプリをアンインストールすることで端末内のデータも削除されますが、Android のバックアップ機能によって保存されたデータが、再インストール時や端末移行時に復元される場合があります。

## 3. モバイル端末と Wear OS 端末間の同期

本アプリでは、モバイル端末と Wear OS 端末の間で、リクエスト設定や実行結果等を同期する場合があります。

この同期には、Google Play 開発者サービスが提供する Wearable Data Layer API を利用します。

同期において当方が運営するサーバーを経由することはありませんが、通信には Google が提供するサービスが利用される場合があります。

## 4. ユーザーが指定した送信先との HTTP 通信

本アプリの主な機能は、ユーザー自身が入力・設定した URL に対して HTTP リクエストを送信することです。

HTTP リクエストは、ユーザーの端末からユーザーが指定した送信先へ送信され、当方が運営するサーバーを経由しません。

本アプリには、HTTP リクエストの送信先 URL、ヘッダー、リクエストボディ、レスポンス内容等を当方が運営するサーバーへ転送・保存する仕組みはありません。

送信先が第三者の管理するサーバーまたはサービスである場合、送信された情報の取り扱いについては、当該送信先のプライバシーポリシーその他の規定が適用されます。

## 5. 情報の取得停止

本アプリをアンインストールすることで、Firebase Crashlytics への新たな情報送信は停止します。

既に Firebase Crashlytics に送信された情報については、Google 社の保存・削除方針に従って取り扱われます。

## 6. 第三者サービスの利用

本アプリでは、機能提供および不具合解析のために、以下の第三者サービスを利用します。

- Firebase Crashlytics
- Google Play 開発者サービス（Wearable Data Layer API）
- Android のバックアップ・端末移行機能（ユーザーの端末設定等により利用される場合があります）

これらのサービスにおける情報の取り扱いについては、各サービス提供者が定めるプライバシーポリシーその他の規定をご確認ください。

## 7. 第三者への提供

当方は、法令に基づき開示または提供を求められた場合を除き、本アプリを通じて当方が取得した情報を第三者へ提供しません。

なお、ユーザー自身が本アプリを利用して指定した送信先へ HTTP リクエストを送信すること、および本ポリシーに記載した第三者サービスを本アプリが利用することは、この項目における当方からの第三者提供とは区別して取り扱います。

## 8. プライバシーポリシーの改訂

当方は、本プライバシーポリシーを必要に応じて見直し、変更することがあります。

変更した場合は、当ページにて公開します。
