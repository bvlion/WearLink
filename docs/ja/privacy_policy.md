# 【WearLink】プライバシーポリシー

当方が提供するアプリケーション「WearLink」（以下「本アプリ」といいます。）における情報の取り扱いについて、以下のとおりお知らせします。

## 1. 本アプリが取得・保存する情報

本アプリは、ユーザーが作成・実行する HTTP リクエストに関する以下の情報を、本アプリのローカルストレージ（端末内）に保存します。

- リクエストのタイトル
- URL
- HTTP メソッド
- ヘッダー
- リクエストボディ
- その他のリクエスト設定
- レスポンスコード
- レスポンスヘッダー
- レスポンスボディ
- 実行日時等の実行履歴

これらは、いずれもユーザー自身が本アプリの機能を利用するために作成する情報であり、本アプリの機能提供（作成したリクエストの管理・実行、および実行履歴の表示）のためにのみ保存されます。位置情報、個人を特定する情報、健康情報、メッセージ、写真・動画、音声、ファイル、カレンダー、連絡先、ウェブ閲覧履歴、クラッシュログ・診断情報、端末識別子等を本アプリが取得することはありません。

これらの情報を、当方が運営するサーバーへ送信・保存する仕組みはありません。

ただし、Android のバックアップまたは端末移行機能が有効な場合、Android の機能によりこれらのデータがバックアップまたは別の端末へ復元・転送される場合があります。

端末内に保存された情報は、本アプリ内の削除機能によって削除できます。また、通常は本アプリをアンインストールすることで端末内のデータも削除されますが、Android のバックアップ機能によって保存されたデータが、再インストール時や端末移行時に復元される場合があります。

## 2. モバイル端末と Wear OS 端末間の同期

本アプリでは、モバイル端末と Wear OS 端末の間で、リクエスト設定や実行結果等を同期する場合があります。

この同期には、Google Play 開発者サービスが提供する Wearable Data Layer API を利用します。

同期において当方が運営するサーバーを経由することはありませんが、通信には Google が提供するサービスが利用される場合があります。

## 3. ユーザーが指定した送信先との HTTP 通信

本アプリの主な機能は、ユーザー自身が入力・設定した URL に対して HTTP リクエストを送信することです。この送信先および送信内容は、当方ではなくユーザー自身が指定するものであり、当方が任意に第三者へ情報を提供・共有するものではありません。

本アプリは HTTP・HTTPS の両方の通信方式に対応しています。ユーザーが送信先として HTTP（暗号化されていない通信）の URL を指定した場合、リクエストおよびレスポンスの内容が暗号化されずに通信される場合があります。通信内容が暗号化されるかどうかは、ユーザーが指定する送信先の設定に依存します。

HTTP リクエストは、ユーザーの端末からユーザーが指定した送信先へ直接送信され、当方が運営するサーバーを経由しません。本アプリには、送信先 URL、ヘッダー、リクエストボディ、レスポンス内容等を当方が運営するサーバーへ転送・保存する仕組みはありません。

送信先が第三者の管理するサーバーまたはサービスである場合、送信された情報の取り扱いについては、当該送信先のプライバシーポリシーその他の規定が適用されます。

## 4. アカウントおよびデータの削除について

本アプリは、アプリ内でのアカウント作成、および外部サービスのアカウントを用いたログイン機能を提供していません。

端末内に保存された情報（本ポリシー第 1 項に記載のもの）は、本アプリ内の削除機能、またはアプリのアンインストールにより削除できます（Android のバックアップ機能により復元される場合がある点は同項に記載のとおりです）。

一方、ユーザー自身が指定した送信先へ既に送信済みの HTTP リクエストの内容については、当方が保持しているものではないため、当方側で削除することはできません。送信済みのデータの削除をご希望の場合は、送信先の運営者に直接お問い合わせください。

## 5. 外部の解析・不具合収集 SDK について

本アプリでは、以前は Firebase Crashlytics を利用していましたが、現在は利用を終了しています。本アプリは、Firebase を含む Google 社の Firebase SDK、および利用状況の分析やクラッシュ・診断情報の収集を目的とした他社製の SDK（Analytics SDK、クラッシュレポート SDK、テレメトリ SDK 等）を一切利用していません。

このため、本アプリの利用状況やクラッシュログ・診断情報等が、外部の解析サービスへ送信されることはありません。

なお、これは外部解析 SDK を利用していないという趣旨であり、本ポリシー第 2 項に記載するモバイル端末と Wear OS 端末間の同期（Wearable Data Layer API）や、Android のバックアップ・端末移行機能の利用を否定するものではありません。

## 6. 第三者サービスの利用

本アプリでは、以下の第三者サービスを利用します。

- Google Play 開発者サービス（Wearable Data Layer API。モバイル端末と Wear OS 端末間の同期のために利用します。）
- Android のバックアップ・端末移行機能（ユーザーの端末設定等により利用される場合があります。）

これらのサービスにおける情報の取り扱いについては、各サービス提供者が定めるプライバシーポリシーその他の規定をご確認ください。

なお、ユーザー自身が指定した送信先についても、それぞれの運営者が定めるプライバシーポリシー等が適用されます（本ポリシー第 3 項参照）。

## 7. 第三者への提供

当方は、法令に基づき開示または提供を求められた場合を除き、本アプリを通じて当方が取得した情報を第三者へ提供しません。

なお、ユーザー自身が本アプリを利用して指定した送信先へ HTTP リクエストを送信すること、および本ポリシーに記載した第三者サービスを本アプリが利用することは、この項目における当方からの第三者提供とは区別して取り扱います。

変更した場合は、当ページにて公開します。
